# Nightclub UI prototypes

Interactive web and mobile frontend concepts for a community of collaborators and builders.

## Live previews

- [Open mobile prototype](https://deepdive-ai.github.io/nightclub-ui/NIGHTCLUB_MOBILE_MASCOT_GP.html)
- [Open web prototype](https://deepdive-ai.github.io/nightclub-ui/NIGHTCLUB_FRONTEND_BUBBLEGUM_DARKER_CARDS_GP.html)

Anyone can open these links without signing in. The HTML downloads also work as standalone files; demo changes stay in each visitor’s browser.

## Files

- [Mobile prototype](NIGHTCLUB_MOBILE_MASCOT_GP.html): compact mobile layout, bottom navigation, four-character artwork, and a tappable guide mascot.
- [Web prototype](NIGHTCLUB_FRONTEND_BUBBLEGUM_DARKER_CARDS_GP.html): illustrated glass cards, bubblegum headline, and desktop layout.
- [Mobile guide](NIGHTCLUB_MOBILE_GUIDE.md).
- [Web frontend specification](NIGHTCLUB_DARKER_CARDS_FRONTEND.md).

Download an HTML file using GitHub’s Download raw file option, then open it in a browser. Each HTML embeds its styles, scripts, and artwork. No build or dependency installation is required. GitHub’s file viewer displays source code. The prototypes are also published through GitHub Pages using the links above.

## Prototype scope

All people, projects, listings, and events are illustrative. Changes remain in browser storage. There is no live authentication, backend, payment processing, AI assistant, or real message delivery. The LocalLoop progress badge means tasks accepted after review, not members in a circle.

## Artwork

Illustrations were generated specifically for the prototype. Visual references included [Adam Vicarel’s sticker system](https://dribbble.com/shots/27813696-Stickers-and-Illustration-System-for-Brewery-Merchandise), [Yuyu Kangkang](https://dribbble.com/shots/27848321-Yuyu-Kangkang-A-Javanese-Folktale), and [Galerinhas by Ina Gouveia](https://www.behance.net/gallery/257675379/Galerinhas). Their original artworks are not embedded. The small lavender guide mascot is an original SVG graphic.
